                        Privacy

                        Your notes, folders, tags, tasks, reminders, chat history and settings are stored only in this browser (localStorage). There is no account and no Setrof server. Clearing your browser data, or using a private window, erases them.

                        This data is not encrypted and there is no passcode lock, so anyone who can use this browser profile can read it.

                        Some chat questions call public web services, and only what you ask about is sent: Open-Meteo (weather), OpenStreetMap Nominatim (place name for your coordinates), Frankfurter (currency rates), Free Dictionary API (definitions), REST Countries (country facts) and Wikipedia (capital photos). Your notes are never sent anywhere.
